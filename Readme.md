## 🧭 What I Do

I design and operate **end-to-end data infrastructure** — from ingestion to serving — with a strong emphasis on reliability and observability.

- **Real-time Pipelines** — Event-driven architectures using Kafka + Debezium (CDC), following strict Medallion Architecture (Bronze → Silver → Gold)
- **Observability & Lineage** — Automated Grafana provisioning, full data lineage tracking via OpenMetadata, and AI-driven Root Cause Analysis built on a Palantir-inspired Ontology
- **AI & Search** — Knowledge Graphs (Memgraph), config-driven ETL frameworks, and high-performance Geospatial/POI search APIs via Elasticsearch
- **ML Engineering** — Experience with TensorFlow, Keras, and OpenCV for applied ML use cases
