## 🧭 What I Do

I design and operate **end-to-end data infrastructure** — from ingestion to serving — with a strong emphasis on reliability, observability, and AI integration.

- **Real-time Pipelines** — Event-driven architectures using Kafka + Debezium (CDC), following strict Medallion Architecture (Bronze → Silver → Gold)
- **Observability & Lineage** — Automated Grafana provisioning, full data lineage tracking via OpenMetadata, and AI-driven Root Cause Analysis built on a Palantir-inspired Ontology
- **AI & Data Agents** — Integrating LLMs into workflows via async microservices (RabbitMQ + Redis + Qdrant), RAG implementations, and Knowledge Graphs (Memgraph)
- **Cloud & Lakehouse** — Architecting scalable cloud platforms and evaluating infrastructure utilizing BigQuery, Snowflake, Databricks, and PySpark
